# Welcome to ByteNotes

ByteNotes is an open-source, community-driven platform for software engineering interview notes.

## 🔗 GitHub Repository
You can find the entire source code and contribute to the notes at our [GitHub Repository](https://github.com/rajmpawar-hash/ByteNotes).

## Contributing
To add a new note, simply create a new markdown file in the appropriate folder under `src/notes/`.

- The sidebar navigation is automatically generated based on the folder structure!
- Use standard markdown syntax.

> Enjoy the beautiful reading experience!
