# Welcome to ByteNotes

ByteNotes is a premium, open-source platform for software engineering interview notes featuring highly visual mindmaps and diagrams.

## 🔗 GitHub Repository
You can find the entire source code and contribute to the notes at our [GitHub Repository](https://github.com/rajmpawar-hash/ByteNotes).

## Contributing
To add a new note, simply create a new markdown file in the appropriate folder under `src/notes/`. The sidebar navigation and the category cards below are automatically generated based on the folder structure!

> Enjoy the beautiful reading experience!
